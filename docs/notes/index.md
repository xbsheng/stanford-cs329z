## 阅读约定

- **页码**：正文中的 `Slide N` 指该讲 PDF 的第 N 页，与课件页码一致。
- **图片**：关键 slides 以 WebP 格式、原 PDF 的 2 倍分辨率渲染，点击图片可查看大图。
- **术语**：中文叙述 + 英文术语；首次出现时给出英文原文，便于检索论文。
- **公式**：使用 KaTeX 渲染，记号尽量与课件保持一致。
- **范围**：笔记是二次整理，不替代原始课件；公式、数字与引用以 slides 为准。
- **讲次**：当前覆盖已发布 slides 的 10 讲；其余讲次见 [课程日程](../schedule)。
